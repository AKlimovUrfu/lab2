# Лабораторная работа №2. Pandas и корреляционный анализ

Цель работы — научиться загружать и преобразовывать табличные данные, строить
простые агрегаты, искать пропуски и интерпретировать коэффициент корреляции
Пирсона.

Работайте в двух файлах: `pandas_tasks.py` и `correlation_tasks.py`. Замените
`raise NotImplementedError` реализациями функций. Имена функций, их параметры,
аннотации и директорию `grader_contracts` менять не нужно. Можно добавлять
собственные вспомогательные функции и необязательные параметры.

В репозитории оставлены исходные ноутбуки `pandas.ipynb` и `correlation.ipynb`:
они содержат пояснения и материал для самостоятельных экспериментов. Основной
формат сдачи — Python-файлы с указанными функциями.

## Часть 1. Titanic и Pandas

Реализуйте `analyze_titanic`. Функция получает путь к `titanic.csv` в объекте
`TitanicInput` и возвращает `TitanicSummary`.

Нужно:

1. загрузить CSV в `DataFrame`;
2. посчитать количество пропусков в каждом столбце;
3. посчитать число пассажиров старше 30 лет;
4. вычислить средний возраст для каждого значения `Pclass`;
5. вычислить долю выживших для каждого `Pclass`;
6. вернуть пять наибольших значений `Fare` в порядке убывания.

Пропуски возраста не должны искусственно превращаться в возраст 0 при расчёте
среднего. В словарях ключи классов должны быть целыми числами.

## Часть 2. Корреляционный анализ

Реализуйте `analyze_brain_correlations`. Функция получает путь к
`brainsize.txt` в объекте `BrainDataInput` и возвращает
`BrainCorrelationSummary`.

Нужно загрузить таблицу с разделителем tab, корректно обработать обозначения
пропусков `NA`, разделить наблюдения на мужчин и женщин и отдельно для каждой
группы посчитать корреляции Пирсона признаков `FSIQ`, `VIQ`, `PIQ`, `Weight`,
`Height` с `MRI_Count`.

В `strongest_mri_feature` верните название признака, у которого модуль
корреляции с `MRI_Count` максимален среди результатов обеих групп. Не включайте
в поиск сам `MRI_Count`.

Для себя постройте scatter-графики и heatmap корреляций с помощью matplotlib и
seaborn. Их не требуется возвращать из контрактной функции, но они должны быть
в вашем отчёте или ноутбуке с экспериментами.

## Инструменты

Разрешены `pandas`, `numpy`, `matplotlib`, `seaborn`, `scipy`, стандартная
библиотека Python и собственные тесты. Не нужно устанавливать зависимости из
кода: среда проверки уже содержит нужные библиотеки.
